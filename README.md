Most of my time goes into **Flutter, Rust, and Solana**. Before that, I spent a lot of time building things with React and TypeScript, including [Remirror](https://github.com/remirror/remirror).

I like things that feel a little different. A game you play by rotating your phone. An interface that looks hand-drawn. A tool that gets a frustrating bit of development out of the way. I want the things I build to be simple, well-designed, and fun to use.

## Now

I'm working on games with motion controls, expressive characters, and progression that changes how you play. Alongside those, I'm building the libraries and tools I want to use myself.

| Project | What I'm Building |
| --- | --- |
| [Pina](https://github.com/pina-rs/pina) / [PinaPod](https://github.com/pina-rs/pinapod) | Rust tooling for Solana programs, with validated zero-copy data layouts and explicit account checks. |
| [Solana Kit](https://github.com/openbudgetfun/solana_kit) | A Dart port of `@solana/kit`, bringing typed RPC, transactions, signers, and codecs to Dart and Flutter. |
| [Monochange](https://github.com/monochange/monochange) | Version and release tooling for monorepos that use more than one language or package ecosystem. |
| [monopi](https://github.com/ifiokjr/monopi) | One-command setup for Pi, with extensions, themes, prompts, and skills. |
| [Skribble](https://github.com/openbudgetfun/skribble) | Sketchy, hand-drawn UI components for Flutter. |
| [MediaPipe](https://github.com/ifiokjr/mediapipe) | MediaPipe Tasks in Dart and Flutter, including pose, hand, and face tracking. |
| [Bitflip](https://github.com/ifiokjr/bitflip) | A collaborative pixel canvas on Solana, built with Flutter. |
| [Lootbox](https://github.com/pina-rs/lootbox) | An experimental, composable random-reward primitive for Solana. |

I've also been working on [MDT](https://github.com/ifiokjr/mdt) to keep documentation in sync and [Monostyle](https://github.com/ifiokjr/monostyle) to make code readability easier to measure and improve. I want these tools to be useful for both people and coding agents.
